# Project: учёт Алексея

Автоматизация учёта: сопоставление банковских транзакций с первичными документами, генерация отчёта для штойербератора.

## Цель

1. Полностью сопоставить все транзакции (банковские выписки) с первичными документами (входящие/исходящие счета)
2. На основании сопоставления сгенерировать документ для штойербератора по согласованному образцу

## Источник истины

Для сверки — банковские выписки. Транзакция без документа = открытый гэп, требует внимания, не проходит молча.

## Входные данные

- Банковские выписки PDF — неизменяемый эталон из банка, источник истины
- CSV/XLS транзакций из банка — рабочий файл, его можно и нужно дополнять при сопоставлении
- Входящие счета: PDF, приходят на alexey.varivoda@gmail.com (сбор почты настроен)
- Исходящие счета: реестр + сами документы

## Возможности агента

- **Gmail**: скачивать вложения (PDF-счета) из почты через Gmail MCP. Перед скачиванием — проверить, не обработан ли документ уже (по имени/сумме/номеру счёта), не тащить дубликаты
- **Браузер (Playwright)**: заходить на сайты сервисов/поставщиков для скачивания документов, которые не приходят на почту
- **Файловая система**: сохранять документы в согласованную папку хранения (см. договорённости проекта)

## Флоу в два шага

**Шаг 0 — сверка CSV с PDF-выписками.** Перед началом сопоставления проверить, что CSV-экспорт из банка полностью соответствует PDF-выпискам (та же сумма транзакций, ничего не потеряно и не задвоено при экспорте). Расхождение — стоп, разбираться, не работать с искажённым CSV.

**Шаг 1 — сопоставление в CSV.** Работаем прямо в CSV с банковскими транзакциями: к каждой строке дописываются столбцы с реквизитами найденного документа:
- контрагент
- номер счёта
- откуда взят документ (почта/сайт/вручную)
- статус (найден / открытый гэп)

CSV пересобирается построчно по мере обработки, не пересоздаётся с нуля. Это и есть таблица обработанных документов, отдельного файла для неё не заводить.

**Шаг 2 — отчёт для штойербератора.** На основе обогащённого на шаге 1 CSV генерируется итоговый документ по образцу, предоставленному AV (образец = пункт 2.5 договорённостей). Шаг 2 не начинать, пока шаг 1 не закрыт по всем транзакциям месяца.

## Логирование

Каждое действие агента (скачал документ, сопоставил с транзакцией, не нашёл совпадение) — фиксировать прямо в CSV (шаг 1) или в отдельном логе, если действие не привязано к конкретной транзакции. Ничего не делать молча без следа.

## Конвенции

- Финансовые суммы: строки/Decimal, никогда float
- Не переименовывать и не удалять оригиналы документов без явного подтверждения
- Транзакция без найденного документа — явно отмечается как открытый гэп, не пропускается молча
