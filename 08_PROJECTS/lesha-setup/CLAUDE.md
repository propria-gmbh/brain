# Project: учёт Алексея

Автоматизация учёта: сопоставление банковских транзакций с первичными документами, генерация отчёта для штойербератора.

## Цель

1. Полностью сопоставить все транзакции (банковские выписки) с первичными документами (входящие/исходящие счета)
2. На основании сопоставления сгенерировать документ для штойербератора по согласованному образцу

## Источник истины

Для сверки — банковские выписки. Транзакция без документа = открытый гэп, требует внимания, не проходит молча.

## Входные данные

- Банковские выписки: CSV/XLS
- Входящие счета: PDF, приходят на alexey.varivoda@gmail.com (сбор почты настроен)
- Исходящие счета: реестр + сами документы

## Возможности агента

- **Gmail**: скачивать вложения (PDF-счета) из почты через Gmail MCP. Перед скачиванием — проверить, не обработан ли документ уже (по имени/сумме/номеру счёта), не тащить дубликаты
- **Браузер (Playwright)**: заходить на сайты сервисов/поставщиков для скачивания документов, которые не приходят на почту
- **Файловая система**: сохранять документы в согласованную папку хранения (см. договорённости проекта)

## Таблица обработанных документов

Вести файл-таблицу (CSV или markdown, без кода — просто Read/Write) со столбцами:
- дата документа
- контрагент
- сумма
- номер счёта
- откуда взят документ (почта/сайт/вручную)
- привязанная транзакция (или "не найдена")
- статус (обработан / открытый гэп)

Дописывать новую строку при обработке каждого документа, не пересоздавать файл заново.

## Логирование

Каждое действие агента (скачал документ, сопоставил с транзакцией, не нашёл совпадение) — фиксировать в таблице обработанных документов или отдельном логе. Ничего не делать молча без следа.

## Конвенции

- Финансовые суммы: строки/Decimal, никогда float
- Не переименовывать и не удалять оригиналы документов без явного подтверждения
- Транзакция без найденного документа — явно отмечается как открытый гэп, не пропускается молча

- Не удалять файлы/данные без явного разрешения
- Не коммитить credentials/токены в git
